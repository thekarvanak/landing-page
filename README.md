# Juan Camilo Gallo — Ingeniería biomédica

Landing page profesional para presentar servicios de ingeniería clínica, gestión de tecnología biomédica, protección radiológica y automatización de procesos para instituciones de salud.

## Archivos

```text
index.html
css/styles.css
js/main.js
README.md
```

## Ejecución

Abre `index.html` directamente en un navegador moderno. No se requiere servidor, instalación de paquetes ni proceso de compilación.

## Formulario de contacto

El formulario valida los campos obligatorios y el formato del correo en el navegador. Al continuar, prepara un borrador mediante `mailto:` en la aplicación de correo configurada por el visitante. La persona debe revisar y enviar el mensaje desde esa aplicación. El sitio no tiene backend, no transmite ni almacena datos y no confirma la recepción de solicitudes. Si no se abre el correo, aparece un enlace alternativo para escribir directamente.

El formulario advierte que no se deben incluir datos de pacientes ni información clínica identificable.

## Recursos e integraciones

- Ilustración e iconos: SVG incluidos directamente en el HTML.
- Tipografía: pila de fuentes del sistema; no necesita descargar fuentes externas.
- Contacto: correo electrónico, WhatsApp y perfil público de LinkedIn.
- No se incluyen fotografías clínicas, datos de pacientes ni recursos de terceros.
- Las actividades de asesoría radiológica y apoyo documental se acuerdan tras revisar los requisitos y el alcance profesional aplicables. No se garantiza habilitación ni licenciamiento.
